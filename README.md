# 📚 Library Management System using C++ and MySQL

This project is a console-based Library Management System that helps manage books and students, and handles operations such as issuing and returning books.
It demonstrates a complete end-to-end database-driven application using C++ with a MySQL backend.

📌 Problem Statement

Manual management of library records is time-consuming and error-prone.
The goal of this project is to build a system that automates basic library operations like storing book details, managing students, and tracking issued books.

This is a database management application.

## 📊 Database

The project uses a MySQL database with the following main tables:

- books – stores book information

- students – stores student information

- issue – stores issued book records

- Target operations:

- Insert new records

- Fetch records

- Update issue/return status

## ⚙️ Application Workflow

- Functionalities provided by the system:

- Add new books to the database

- Display all available books

- Search books by ID or name

- Issue a book to a student

- Return a book

- View issued book records

- All operations are performed using SQL queries executed from C++.

## 🛠 Tech Stack

- Programming Language: C++

- Database: MySQL

- Connectivity: MySQL Connector

- Interface: Console-based
